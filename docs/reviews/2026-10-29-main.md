## Minor
### 🟡 `document.fonts.ready` may resolve before the font is requested, `src/components/GrapheReseau.tsx:402`
**Problem**: Canvas text does not trigger a webfont load. If the effect runs before the DOM text using Space Grotesk has started loading, `fonts.ready` resolves immediately and the canvas keeps the fallback font until the next redraw. The unmount race itself is safe (`cyRef.current` is nulled in cleanup; StrictMode only triggers one harmless extra update).
**Why it matters**: Intermittent flash/permanent fallback font on graph labels at first load, mainly cosmetic.
**Suggested fix**: Use `document.fonts.load("700 13px 'Space Grotesk Variable'")` (then update), guarded for missing `document.fonts`. The Analyse marking graph (`Analyse.tsx` ~line 154) uses the same font and has no such redraw at all.

### 🟡 Hover erases the `choix` highlight, `src/components/GrapheReseau.tsx:164`
**Problem**: `node.survol` comes after `node.choix` and overrides `underlay-color`/opacity (black 0.15 replaces the yellow underlay), so hovering a selectable choice makes its "pick me" cue disappear.
**Suggested fix**: Place `survol` before `choix`, or use a different property for hover.

### 🟡 Weaker inactive cue, `src/components/GrapheReseau.tsx:149`
**Problem**: `inactif` now fades only background/border (0.4). Franchissable-but-locked transitions (verrouille) stay green at 0.4 with a full-opacity label, which reads as "enabled but pale". Acceptable, but the label no longer signals disabled.
**Suggested fix**: Verify visually in verrouille and choix modes; consider dimming label color slightly (e.g. text-opacity 0.7).
